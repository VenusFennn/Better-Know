# Changelog

## 1.1.0 - 2026-08-27

- 将三个 Skill 的最终方案统一为七个固定顶层章节；
- 增加动态子章节裁剪规则，纯前端和纯后端任务不再输出另一领域的无关内容；
- 全栈技能先判定任务范围，只加载与实际范围匹配的领域技能；
- 迁移、灰度、回滚、混合版本和专项测试只在真实风险触发时展开；
- 增加纯领域误用、动态路由和无关章节抑制评测用例。
