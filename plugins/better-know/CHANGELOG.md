# Changelog

## 1.2.0 - 2026-08-28

- 三个 Skill 新增统一的《方案可读性规范》；
- 关键函数、类、组件、模块、字段、文件、接口、表、Topic、缩写和专业术语首次出现时就地解释职责与任务关系；
- 保留精确技术标识，重复出现时使用中文短称，避免重复解释；
- 多个关键对象集中出现时，按需生成局部“关键对象说明”表，不增加固定第八章节；
- 增加解释证据约束、推断标记、读者自适应和无关科普抑制；
- 更新前端、后端和全栈可读性评测与内容覆盖清单；
- 锁定 Frontend-Solution-Design 1.3.0 与 Backend-Solution-Design 1.3.0 的正式源提交。

## 1.1.0 - 2026-08-27

- 将三个 Skill 的最终方案统一为七个固定顶层章节；
- 增加动态子章节裁剪规则，纯前端和纯后端任务不再输出另一领域的无关内容；
- 全栈技能先判定任务范围，只加载与实际范围匹配的领域技能；
- 迁移、灰度、回滚、混合版本和专项测试只在真实风险触发时展开；
- 增加纯领域误用、动态路由和无关章节抑制评测用例。

## 1.0.0 - 2026-08-27

- 首次发布 Better Know 双平台 Skills-only 插件；
- 打包 `frontend-solution-design` 1.1.0；
- 打包 `backend-solution-design` 1.1.0；
- 新增 `fullstack-solution-design` 1.0.0；
- 为前端和后端技能增加跨端职责、契约与冲突收敛规则；
- 修复前端技能快照中失效的文件哈希记录；
- 增加 Codex 与 Claude Code 插件清单和仓库级 Marketplace；
- 增加来源锁、技能级与插件级 SHA-256 完整性校验。
